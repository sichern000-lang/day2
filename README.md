## 🤖 내 에이전트 한 줄

2026년 하반기에 계획되어 있는 **제주도 축제**에 대해서 알려주는 기능 🏝️

- 🎯 목표: 여행자가 축제를 쉽고 빠르게 찾도록 돕기
- 📅 대상 기간: 2026년 하반기 (7월 ~ 12월)
- 📍 대상 지역: 제주도 전역 (제주시, 서귀포시 포함)
- 🗣️ 사용 언어: 한국어

---

## 👤 사용자 한 명

### 🧑 고창준

- 🧳 제주도 축제를 찾아 방문하려는 사람
- 🔎 날짜, 지역, 분위기를 보고 축제를 고르고 싶어 합니다
- ⏱️ 여러 사이트를 뒤지지 않고 한 번에 알고 싶어 합니다
- 🌦️ 날씨와 사람 수도 함께 고려하고 싶어 합니다

---

## ❓ 사용자가 물어볼 질문 예시 3개

1. 🏙️ **제주시에서 열리는 축제**
2. 👥 **사람이 많이 오는 축제**
3. 🌋 **제주만의 특성이 잘 담긴 축제**

### 🧩 질문별로 필요한 정보

| 번호 | 질문 | 필요한 정보 |
| --- | --- | --- |
| 1️⃣ | 제주시에서 열리는 축제 | 📍 장소, 📅 날짜 |
| 2️⃣ | 사람이 많이 오는 축제 | 👥 작년 방문객 수 |
| 3️⃣ | 제주만의 특성이 잘 담긴 축제 | 🎭 행사 내용, 🌿 지역 특색 |

---

## 🔍 에이전트가 찾아야 할 것

### 🗓️ 1. 계절 날짜별 행사

- 🌸 봄: 해당 없음 (하반기 한정)
- ☀️ 여름 (7~8월): 여름 축제
- 🍂 가을 (9~11월): 가을 축제
- ❄️ 겨울 (12월): 겨울 축제
- 📆 날짜별로 정렬해 보여주기

### 👥 2. 작년 방문객 수와 당시 날씨

- 🔁 작년에 같은 축제가 열렸는지 확인
- 🧮 열렸다면 방문객 수 찾기
- 🌤️ 당시 날씨 함께 찾기
- 📊 방문객 수와 날씨의 관계 살펴보기

### 🌦️ 3. 올해 축제일 날씨

- ☔ 비 소식이 있는지
- 🌡️ 기온은 어떤지
- 💨 바람은 강한지 (제주는 바람이 중요해요 🌬️)
- 🧥 어떤 옷차림이 좋을지

### 🎪 4. 축제에서 진행되는 행사

- 🎨 체험 프로그램
- 📍 체험 장소
- 🎤 공연과 이벤트
- 🍽️ 먹거리
- 🌦️ 날씨 영향 (예: 비가 오면 실내 행사로 바뀌는지)

---

## 🗂️ 정보 정리 방식

에이전트가 답을 줄 때 아래 틀로 정리하면 좋습니다. 📋

```text
🎉 축제 이름:
📅 날짜:
📍 장소:
👥 작년 방문객 수:
🌤️ 작년 날씨:
🌦️ 올해 날씨:
🎪 주요 행사:
🏷️ 제주 특색:
```

### ✅ 좋은 답변의 조건

- ✔️ 날짜가 정확할 것
- ✔️ 출처가 분명할 것
- ✔️ 짧고 읽기 쉬울 것
- ✔️ 이모지로 눈에 잘 들어올 것 😊
